# License status: pending

This repository does **not** currently have a license file, and this is
intentional, not an oversight.

This project was developed in part using Johns Hopkins University resources
(work computer, time supported by an NIH grant as part of the IndigiText
project). Under the JHU Intellectual Property Policy (Oct. 5, 2011, Section
IV.D), software developed using University support is owned by the
University, including copyright. That means the author does not currently
have the authority to unilaterally attach an open-source license — that
decision belongs to Johns Hopkins (typically via the Technology Transfer
Office).

**What this means in practice:**
- The code is public for development-history and collaboration-discussion
  purposes (visibility, issues, transparency).
- In the absence of a license file, standard copyright default applies:
  no one (including outside contributors) has a legal right to copy, modify,
  reuse, or redistribute this code yet.
- The stated goal is a **free, open-source license** (so the tool can reach
  other researchers and communities) once ownership/licensing is confirmed
  with JHU. Apache 2.0 was the working default under consideration, but the
  final choice will be made in consultation with the appropriate JHU office.
- Disclosure to the Johns Hopkins Technology Transfer Office is planned/in
  progress per the University's IP Policy (Section III.A).

This notice will be replaced with a formal LICENSE file once that process is
complete. If you're reading this as a prospective contributor or user:
please don't rely on this code for production use or redistribute it until
a license is in place.
